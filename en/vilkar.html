2. The product

The Journey with Luke is an Advent game in the browser, based on the Gospel of Luke. It is for ages 8 and up, and is bought by an adult.

Door 1 is free to try. The purchase gives you a code that unlocks the rest of the calendar, doors 2 to 24. The doors open on their date in December. If you buy later in December, you can also play the doors that have already opened.

There are no purchases inside the game, no loot boxes and no social log-in. The game has no advertising and no tracking.

The code and your progress are stored in the browser on the device you play on. If you delete your browser data or change device, you can enter the code again.

Personal code and family code

A personal code is meant for one person: the person who buys it, or the person who receives it as a gift.

A family code is for one household, that is everyone who lives in the same home. The family code may be entered on all the devices in the household.

If more people outside the household each want their own calendar, for example grandparents, friends or another family, we hope they will buy their own code.

The game does not count devices and does not know any persons. We trust you and will not block the code only because it is shared. Each purchase makes it possible for us to keep the game free of advertising and tracking, and to make more games like this. Thank you for taking part in that.
